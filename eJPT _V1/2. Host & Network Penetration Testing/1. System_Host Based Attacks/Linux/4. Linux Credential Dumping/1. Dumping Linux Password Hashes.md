```
/etc/passwd
```

Las pass se guardan en el fichero 
```
/etc/shadown 
```

En formato de has. A ese fichero solo tenemos acceso como root 

El fichero passwd nos da informacion del tipo de algoritmo de hash que se esta utilizando para hashear la password. Es muy util para poder determinar la fortaleza del tipo de has. Podemos saberlo mirando el numero despues del username encapsulado por el simbolo de (\$) usuario:\$6$sdsd4234g3gg&*%*


| Value | Hashing Algorithm |
| ----- | ----------------- |
| $1    | MD5               |
| $2    | Blowfish          |
| $5    | SHA-256           |
| $6    | SHA-512           |

### ¿Qué significa "upgrade session"?

Cuando tienes una sesión básica de shell (por ejemplo, una shell de comandos normal), puedes usar `sessions -u` para convertir esa sesión en una sesión Meterpreter, que tiene muchas más funcionalidades (módulos, comandos, scripts).

Por ejemplo:

- Inicialmente tienes una sesión de shell simple, pero quieres pasar a Meterpreter para tener mayor control y funcionalidades.
    
- Usas `sessions -u [ID]` para hacer esta "elevación".

### Requisitos:

- La sesión debe ser un shell interactivo que permita hacer este upgrade.
    
- Meterpreter debe estar disponible para inyectar en el sistema remoto.
