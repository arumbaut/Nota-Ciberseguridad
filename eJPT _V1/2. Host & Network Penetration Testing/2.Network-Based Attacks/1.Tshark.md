Filtros Basicos
```
>tshark -r HTTP_fiel.pcap -Y 'http' | more #Aplicar Filtros -Y

>tshark -r HTTP_fiel.pcap -Y 'ip.src==192.168.1.2 && ip.dst ==192.168.1.5'

>tshark -r HTTP_fiel.pcap -Y 'http.request,method==GET'

>tshark -r HTTP_fiel.pcap -Y 'http.request,method==GET' -Tfields -e frame.time -e ip.src -e http.request.full_uri

>tshark -r HTTP_fiel.pcap -Y 'http contains password' #Para hacer busqueda de conetenido en la peticion

>tshark -r HTTP_fiel.pcap -Y 'http.request,method==GET && http.host==www.nytime.com' -Tfields -e ip.dst 

>tshark -r HTTP_fiel.pcap -Y 'ip contains amazon.in && ip.src==192.168.2.2' -Tfields -e ip.src -e http.cookie 

>tshark -r HTTP_fiel.pcap -Y 'ip.src==192.168.1.2 && http' -Tfields -e http.user_agent
```
