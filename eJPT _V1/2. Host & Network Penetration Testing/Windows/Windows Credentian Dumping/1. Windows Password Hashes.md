 Los hash de los pass de usuariso se almacenan en un bd llamada SAM Database en la siguiente direccion.

- **Ubicación del archivo SAM:**  
    `%SystemRoot%\system32\config\SAM`  
    (normalmente en `C:\Windows\System32\config\SAM`)
    
- **Registro del sistema:**  
    Windows monta este archivo en el registro bajo la clave:  
    `HKEY_LOCAL_MACHINE\SAM`

Este archivo permanece bloqueado por el sistema como medida de seguridad

Los atacantes utilizan herramientas y tecnicas en memoria para extraer los hashes de LSASS (Local Security Authority Subsistem) process memory . LSA (Local Security Authority) Son los responsables de la autenticacion de windows y este proceso tiene una memoria que contiene los valores hash de usuarios para interactuar con el archivo SAM

Se necesitan privilegios elevados para poder extraer los hashh del sistema

LM es el algoritmo de hash pr defecto en Windows
1 El pass es partido en 2 cadenas de 7 caracteres
2 Todos los caracteres se lleva a mayusculas
3 Cada cadena es hasheada de forma separada con el algoritmo DES 

LM es generalmente considerado un protocolo debil y facil de crackear porque el password hash no inclulle salt. Por lo que los ataques de fuerza bruta y raibow table son efectivos contra el.
