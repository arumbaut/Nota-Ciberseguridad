
Los workspaces permiten matener un seguimiento de todos los host , escaneos y actividades y son extremadamente utiles en la conduccion de test de penetracion asi como que te permiten organizar toda la informacion basada en la organizacion objetivo

MSF te permite crear, manejar y cambiar entre multiples workspaces dependiendo de tus requerimientos

```
Verificar la bd es lo primero para que se guarden los datos de los workspaces en metaexploit y no se pierdan al reiniciar la consola

msfconsole
msf6 > db_status 
[*] Connected to msf. Connection type: postgresql.

msf6 > workspace -h
Usage:
    workspace          List workspaces
    workspace [name]   Switch workspace

OPTIONS:

    -a, --add <name>          Add a workspace.
    -d, --delete <name>       Delete a workspace.
    -D, --delete-all          Delete all workspaces.
    -h, --help                Help banner.
    -l, --list                List workspaces.
    -r, --rename <old> <new>  Rename a workspace.
    -S, --search <name>       Search for a workspace.
    -v, --list-verbose        List workspaces verbosely.

msf6 > workspace #Nos muestra cual workspaces estamos utilizando
* default

msf6 > hosts  #Nos muestra info de target previos utilizados en nuestro workspace

Hosts
=====

address  mac  name  os_name  os_flavor  os_sp  purpose  info  comments
-------  ---  ----  -------  ---------  -----  -------  ----  --------

msf6 > workspaces -a Nombre #Crea un workspace
msf6 > workspaces Nombre #Switsh al workspace con el nombre indicado
msf6 > workspaces -d Nombre #Elimina el workspace con ese nombre
msf6 > workspaces -a Old_Nombre New_Nombre  #Renombrar
```
