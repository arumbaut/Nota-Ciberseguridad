Provee de una infraestructura robusta para la automatizacion de cada etapa del ciclo de vida de las pruebas de penetracion. Esencialmente la explotacion y postexplotacion.

Tambien cuenta con la BD publica de pruebas exploids mas grande.

Disennado para ser modular permitiendo que sen implementadas nuevas funcionalidades de manera sencilla

Todo lo que se quiera lanzar desde metasploit se empieza por 
```
>msfconsole
```

MSFcli -> Se utiliza para facilitar la creacion de scripts automaticos que utilizan los modulos de metasploit. Puede ser utilizado para redirigr la salida de otras herramientas a msfcli y viceversa

Metaspliot Community Edition es una GUI web  para el framework de metasploit que simplifica el network discovery y la identificacion de vulnerabilidades

Iniciar la base de datos si no esta corriendo
```
sudo systemctl enable postgresql
sudo systemctl start postgresql
```
