MSF Variables de Modulos

|Variable|Descripción|
|---|---|
|**LHOST**|Almacena la dirección IP del sistema del atacante.|
|**LPORT**|Almacena el número de puerto en el sistema del atacante que se utilizará para recibir una conexión inversa.|
|**RHOST**|Almacena la dirección IP del sistema/servidor objetivo.|
|**RHOSTS**|Especifica las direcciones IP de múltiples sistemas objetivo o rangos de red.|
|**RPORT**|Almacena el número de puerto que se está atacando en el sistema objetivo.|

Para ver las opciones que se deben configurar en un modulo
```
msf6 auxiliary(scanner/portscan/tcp)>show options

Opciones del módulo (auxiliary/scanner/portscan/tcp):

| Nombre               | Configuración actual | Requerido | Descripción |
|----------------------|---------------------|-----------|-------------|
| CONCURRENCY         | 10                  | sí        | Número de puertos concurrentes a verificar por host |
| DELAY               | 0                   | sí        | Retardo entre conexiones, por hilo, en milisegundos |
| JITTER              | 1                   | sí        | Factor de variación del retardo (valor máximo +/- DELAY) en ms |
| PORTS               | 1-10000             | sí        | Puertos a escanear (ej. 22-25,80,110-900) |
| RHOSTS              |                     | sí        | Host(s) objetivo, ver [documentación](https://github.com/rapid7/metasploit-framework/wiki/Using-Metasploit) |
| THREADS             | 1                   | sí        | Número de hilos concurrentes (máximo uno por host) |
| TIMEOUT             | 1000                | sí        | Tiempo de espera para conexión de socket en ms |
```

Establecer un valor al una opcion
```
msf6 auxiliary(scanner/portscan/tcp)>set RHOSTS 10.10.11.34
```

Ejecutar un modulo 
```
msf6 auxiliary(scanner/portscan/tcp)>run || exploit
```

Dejar de utilizar un modulo
```
msf6 auxiliary(scanner/portscan/tcp)>back
msf6>
```
