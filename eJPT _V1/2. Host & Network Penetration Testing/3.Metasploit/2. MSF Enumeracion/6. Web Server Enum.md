Web server trabaja sobre el protocolo de aplicacion HTTP que trabaja sobre TCP 80

Metasploit cuenta con modulos auxiliares para hacer enumeracion sobre este protocolo para obtener la version , headers y realizar fuerza bruta de directorios y mas

ejemplo de Web Server populares Apache , Nginx, Microsoft IIS

```
mfsconsole
msf6>workspace -a WEB_SERV_ENUM
msf6>setg RHOST ip
msf6>setg RHOSTS ip
msf6>search type:auxiliary name:http -name:*version* || 
msf6>search type:auxiliary http version #Resalta las palabras de la busqueda 

msf6>use auxiliary/scanner/http/http_version
msf6 auxiliary(scanner/http/http_version)>show options

Para web servers que utilicen ssl se debe cambiar el puerto asi como activar la negociacion del SSl sino lo dejamos por default
example
msf6 auxiliary(scanner/http/http_version)>set SSL true
msf6 auxiliary(scanner/http/http_version)>run

Enumerar los headers
msf6>search type:auxiliary http header
msf6>use auxiliary/scanner/http/http_header
msf6 auxiliary(scanner/http/http_header)>show options
msf6 auxiliary(scanner/http/http_header)>run


Enumerar directorion en el Web Server
msf6>search type:auxiliary robots_txt
msf6>use auxiliary/scanner/http/robots_txt
msf6 auxiliary(scanner/http/robots_txt)>show options
msf6 auxiliary(scanner/http/robots_txt)>run  #Muestra rutas sensibles o privadas en el archivo robots.txt
msf6 auxiliary(scanner/http/robots_txt)>curl ip/directoy_found/

### 🔍 ¿Qué hace este módulo? auxiliary/scanner/http/robots_txt

Este módulo automatiza el proceso de:
1. Solicitar el archivo `robots.txt` desde un sitio web.    
2. Analizar las **directivas "Disallow"** (y otras) dentro del archivo.    
3. Mostrar rutas que **podrían ser sensibles o privadas**, como:
    


#Hacer un directory brute force
msf6>search type:auxiliary dir_scanner
msf6>use auxiliary/scanner/http/dir_scanner
msf6 auxiliary(scanner/http/dir_scanner)>show options
msf6 auxiliary(scanner/http/dir_scanner)>run  #nos muestra los directorios que encontra


#Escaner de ficheros
msf6>search type:auxiliary files_dir    
msf6>use auxiliary/scanner/http/files_dir
msf6 auxiliary(scanner/http/files_dir)>show options
msf6 auxiliary(scanner/http/files_dir)>run    #Nos muestra los ficheros que encuentra


#Permite hacer fuerza bruta a la autenticacion 
msf6>search type:auxiliary http_login  
msf6>use auxiliary/scanner/http/http_login 
msf6 auxiliary(scanner/http/http_login )>show options
msf6 auxiliary(scanner/http/http_login )>set AUTH_URI /secure/ #secure es un directorio restringido en el web server
msf6 auxiliary(scanner/http/http_login )>unset USER_PASSFILE #Desetear un valor
msf6 auxiliary(scanner/http/http_login )>set USER_FILE /usr/share/metasploit-framework/data/wordlists/namelist.txt
msf6 auxiliary(scanner/http/http_login )>set USER_PASSWORD /usr/share/metasploit-framework/data/wordlists/unix_passwords.txt
msf6 auxiliary(scanner/http/http_login )>set VERBOSE false #Para que solo muestre los correctos
msf6 auxiliary(scanner/http/http_login )>run

#Enumerar directorios de apache web server nos ayuda a identificar usuarios en el servidor
msf6 auxiliary(scanner/http/http_login )>search apache_userdir_enum
msf6 auxiliary(scanner/http/http_login )>use auxiliary/scanner/http/apache_userdir_enum

msf6 auxiliary(scanner/http/apache_userdir_enum) >show options
msf6 auxiliary(scanner/http/apache_userdir_enum) >info #Muestra la ayuda del modulo
msf6 auxiliary(scanner/http/apache_userdir_enum) >set USER_FILE /usr/share/metasploit-framework/data/wordlists/commun_users.txt

#Despues de obtener algunos usuarios podemos realizar fuerza bruta
msf6>use auxiliary/scanner/http/http_login
msf6 auxiliary(scanner/http/http_login )>set AUTH_URI
msf6 auxiliary(scanner/http/http_login )>echo "rooty" > user.txt
msf6 auxiliary(scanner/http/http_login )>pwd
msf6 auxiliary(scanner/http/http_login )>set USER_FILE /dir/user.txt
msf6 auxiliary(scanner/http/http_login )>set USER_PASSWORD /usr/share/metasploit-framework/data/wordlists/unix_passwords.txt
```
