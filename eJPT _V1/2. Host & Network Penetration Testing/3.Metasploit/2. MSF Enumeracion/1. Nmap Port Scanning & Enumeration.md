Metasploit permite la integracion con herramientas de 3ro como Nmap

1 Haremos un scaneo con nmap y la salida la importaremos con metasploit y exploraremos el proceso de exportacion

Scaneos 

Basico
```
nmap ip
```

Evitar que envie hacer un ping, solo hace el scan. Se utiliza cuando en ocaciones las pc tienen bloqueado el ping y no da resultados nmap entonces le limitamos esta opcion.
```
nmap -Pn ip
```

Para saber las versiones de los servicios que se ejecutan en el target y el SO del target
```
nmap -Pn -sV -O ip
```

Exportar la salida nmap en un file que pueda ser importado por msf. Se puede especificar la ruta donde queremos se cree el file
```
nmap -Pn -sV -O ip -oX nombre_fichero 

nmap -Pn -sV -O ip -oX /home/usuario/Scan/nombre_fichero 
```
