Los modulos auxiliares son utilizados para realizar  funcionalidades como scanning, discovery y fuzzing

Se pueden para realizar TCP y UDP scanning, es utilizado durante el information gathering y la fase de post-explotacion ademas de utilizarlo para el host discover y el scaneo de red en diferentes subredes una ves ganado acceso al host objetivo
