Protocolo de comunicacion utilizadao para la transmision de correos
Utiliza TCP en el puerto 25 por defecto, tambien se puede configurar en los puertos TCP 465 y 587

```
msfconsole
msf6>workspace -a SMTP_ENUM
msf6>search type:auxiliary name:smtp
msf6> use /auxiliary/scanner/ssh/smtp_version
msf6 auxiliary(scanner/ssh/smtp_version)>show options
msf6 auxiliary(scanner/ssh/smtp_version)>set RHOSTS ip
msf6 auxiliary(scanner/ssh/smtp_version)>run
```

Enumerar SMTP
```
msf6>search type:auxiliary name:smtp
msf6> use /auxiliary/scanner/ssh/smtp_enum
msf6 auxiliary(scanner/ssh/smtp_version)>show options
msf6 auxiliary(scanner/ssh/smtp_version)>set RHOSTS ip
msf6 auxiliary(scanner/ssh/smtp_version)>run
```
