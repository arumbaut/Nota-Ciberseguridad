```
mfsconsole
msf6>db_status
msf6>workspace -a Windows2012
msf6>db_import /dir/nombre_file  #Importamos el file generado con nmap
msf6>hosts #Confirmamos que la importacion fue correcta
msf6>services #Imprime los servicios de los hosts que hemos import
```

Iniciar nmap dentro del framework de metasploit, para esto utilizamos db_nmap que es como msf llama a nmap los parametros y demas son igual

```
msf6>db_nmap -Pn -sV -O ip
```

Nota: De esta manera los resultados se guardan automaticamente en msf en nuestro workspace

Para listar una lista de vulnerabilidades encontradas
```
msf6>vulns
```
