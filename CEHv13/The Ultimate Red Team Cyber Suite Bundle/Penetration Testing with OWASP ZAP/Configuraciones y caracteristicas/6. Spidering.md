
El **Spider** es una herramienta que explora automáticamente un sitio web para descubrir nuevas URLs.  
Parte de unas **semillas** (URLs iniciales), visita cada página, extrae los enlaces y los agrega a la lista para seguir recorriendo el sitio de forma recursiva.  
Se configura desde el diálogo de Spider y, en cada petición, analiza la respuesta para identificar hipervínculos.


Estas se encuentran cuando agregamos una url y les damos click-derecho tenemos las 2 opciones .
AJAX Spider    y  el    Default Spider

Difereincia entre ?
## 🔹 Default Spider (Spider clásico)

- **Cómo funciona:**
    
    - Descarga las páginas web.
        
    - Extrae enlaces, formularios y referencias en HTML, JavaScript estático, CSS, etc.
        
    - Los sigue de manera **recursiva** hasta que ya no encuentra más.
        
- **Limitación:**
    
    - Solo descubre recursos visibles en el HTML o referencias estáticas.
        
    - **No ejecuta JavaScript dinámico**, por lo que no detecta URLs cargadas mediante AJAX o frameworks modernos (React, Angular, Vue, etc.).
        
- **Uso recomendado:**
    
    - Sitios tradicionales con HTML estático o donde los enlaces se encuentran en el código fuente de la página.
        

---

## 🔹 AJAX Spider

- **Cómo funciona:**
    
    - Utiliza un navegador **controlado automáticamente por ZAP** (a través de Selenium/WebDriver).
        
    - Renderiza la página como lo haría un usuario real, **ejecutando JavaScript, AJAX, y llamadas dinámicas**.
        
    - Interactúa con la app: sigue menús, botones, peticiones XHR, etc.
        
- **Ventaja:**
    
    - Puede descubrir URLs y recursos que no están en el HTML original, sino que se cargan dinámicamente en tiempo de ejecución.
        
- **Uso recomendado:**
    
    - Aplicaciones modernas con **AJAX, SPA (Single Page Applications)**, o frameworks JS que generan rutas dinámicas.
        

---

## 🔹 Resumen rápido

- **Default Spider** → rápido, ligero, ideal para HTML tradicional.
    
- **AJAX Spider** → más lento pero necesario en apps modernas con JavaScript dinámico.
    
- Lo habitual: **usar ambos** en conjunto para mayor cobertura.
