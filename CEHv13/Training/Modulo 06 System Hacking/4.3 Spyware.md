Es un software de monitoreo sigiloso que permite registrar en secreto todas las actividades de un usuario en una computadora objetivo. Este software envía automáticamente registros a un atacante remoto a través de Internet, utilizando distintos métodos como correo electrónico, FTP, servidores de comando y control mediante tráfico cifrado, HTTP o DNS.

El spyware es similar a un troyano, ya que suele ocultarse como un componente dentro de software gratuito (freeware) o aplicaciones descargadas de Internet. Para evitar su detección y eliminación, oculta sus procesos, archivos y otros elementos del sistema.

**Spyware Tools**

**▪ Spytech SpyAgent**
**Fuente:** [https://www.spytech-web.com](https://www.spytech-web.com)
es un software espía para computadoras que permite monitorear en total secreto todo lo que los usuarios hacen en el equipo. SpyAgent ofrece una amplia gama de funciones esenciales de monitoreo, así como bloqueo de sitios web, aplicaciones y clientes de chat, programación de registros, y entrega remota de registros vía correo electrónico o FTP.

**▪ Spyrix Personal Monitor**
Fuente: [https://www.spyrix.com](https://www.spyrix.com)
Spyrix Personal Monitor es una herramienta de monitoreo remoto de actividades de usuarios que permite realizar vigilancia oculta a través de una cuenta web segura. Esta herramienta también permite a los atacantes registrar pulsaciones de teclas (keylogging), capturar pantallas, ver en vivo la pantalla y la cámara web, entre otras funciones.
