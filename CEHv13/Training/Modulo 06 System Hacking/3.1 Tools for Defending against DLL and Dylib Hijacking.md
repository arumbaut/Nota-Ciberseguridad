#### ▪ Dependency Walker  
Fuente: [http://www.dependencywalker.com](http://www.dependencywalker.com)  
Dependency Walker es útil para resolver errores del sistema relacionados con la carga y ejecución de módulos. Detecta muchos problemas comunes en aplicaciones, como módulos faltantes, módulos inválidos, desajustes en importación/exportación, errores de dependencia circular,

#### ▪ Dylib Hijack Scanner  
Fuente: [https://objective-see.com](https://objective-see.com)  
Dylib Hijack Scanner (DHS) es una utilidad sencilla que escanea tu computadora para detectar aplicaciones que sean susceptibles a secuestro de dylib (dylib hijacking) o que ya hayan sido secuestradas.  

#### ▪ Spectre & Meltdown Checker  
Fuente: [https://github.com](https://github.com)  
Spectre & Meltdown Checker es un script de shell diseñado para determinar si un sistema es vulnerable a varias CVEs relacionadas con la “ejecución especulativa”. ==Para sistemas Linux, el script detecta mitigaciones, incluyendo parches no estándar backporteados, sin importar la versión del kernel o la distribución (como Debian, Ubuntu, CentOS, RHEL, Fedora, openSUSE, Arch, etc.).==
