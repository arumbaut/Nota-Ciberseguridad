**▪ DDoS Attack:** Un atacante convierte los dispositivos en un ejército de botnets para atacar un sistema o servidor específico, haciéndolo indisponible para proporcionar servicios..

**▪ Attack on HVAC Systems:** as vulnerabilidades del sistema HVAC son explotadas por atacantes para robar información confidencial como credenciales de usuario y realizar ataques adicionales en la red objetivo..

**▪ Rolling Code Attack:** Un atacante interfiere y analiza la señal para obtener el código transferido al receptor de un vehículo; luego lo utiliza para desbloquear y robar el vehículo.

**▪ BlueBorne Attack:** Los atacantes se conectan a dispositivos cercanos y explotan las vulnerabilidades del protocolo Bluetooth para comprometer el dispositivo.

**▪ Jamming Attack:** Un atacante interfiere la señal entre el emisor y el receptor con tráfico malicioso que impide que los dos extremos se comuniquen entre sí.

**▪ Remote Access using Backdoor:** Los atacantes explotan vulnerabilidades en el dispositivo IoT para convertirlo en una puerta trasera y obtener acceso a la red de una organización.

**▪ Remote Access using Telnet:** Los atacantes explotan un puerto telnet abierto para obtener información que se comparte entre los dispositivos conectados, incluidos sus modelos de software y hardware.
