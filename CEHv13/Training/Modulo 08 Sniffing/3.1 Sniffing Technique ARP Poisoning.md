**What Is Address Resolution Protocol (ARP)?**

El **ARP (Address Resolution Protocol)** ==es un protocolo **sin estado** de TCP/IP que mapea las direcciones IP de una red a las direcciones (direcciones de hardware) utilizadas por un protocolo de enlace de datos.Usando este protocolo, un usuario puede obtener fácilmente la **dirección MAC** de cualquier dispositivo.==

**ARP Spoofing Attack**

==ARP resuelve las direcciones IP a las direcciones MAC (hardware) de las interfaces para enviar datos. El ARP spoofing consiste en construir una gran cantidad de paquetes ARP de solicitud y respuesta falsificados para sobrecargar un switch. Cuando una máquina envía una solicitud ARP, asume que la respuesta ARP provendrá de la máquina correcta. Sin embargo, ARP no ofrece ningún medio para verificar la autenticidad del dispositivo que responde. Incluso los sistemas que no han realizado una solicitud ARP pueden aceptar las respuestas ARP que provienen de otros dispositivos. Una vez que la tabla ARP está inundada con respuestas ARP falsificadas, el switch se pone en modo de reenvío, y el atacante intercepta todos los datos que fluyen desde la máquina víctima sin que esta se dé cuenta del ataque.==

==Los atacantes inundan la caché ARP de una computadora objetivo con entradas falsificadas, lo que también se conoce como envenenamiento ARP (ARP poisoning).== El ARP spoofing es un medio para realizar ataques como DoS (Denegación de Servicio), MITM (Man-in-the-Middle) y secuestración de sesión (session hijacking).

**Nota :** El ARP Spoofing es el acto de enviar ARP falsos y  el ARP Poisoning es el resultado o efecto que genera el ARP Spoofing.

#### **How to Defend Against ARP Poisoning**

La Inspección Dinámica de ARP (DAI) previene los ataques de envenenamiento ARP. DAI es una función de seguridad que valida los paquetes ARP en una red. Cuando DAI se activa en una VLAN, todos los puertos en la VLAN se consideran no confiables de forma predeterminada.

DAI valida los paquetes ARP utilizando una tabla de vínculos de DHCP snooping. La tabla de vínculos de DHCP snooping contiene las direcciones MAC, direcciones IP y interfaces VLAN adquiridas mediante la escucha de intercambios de mensajes DHCP. Por lo tanto, debes habilitar DHCP snooping antes de habilitar DAI

**Configuring DHCP Snooping and Dynamic ARP Inspection on Cisco Switches**

Configuring DHCP snooping in global configuration mode

Switch(config)# ip dhcp snooping
Configuring DHCP snooping for a VLAN
Switch(config)# ip dhcp snooping vlan 10
Switch(config)# ^Z

To view the DHCP snooping status
Switch# show ip dhcp snooping
Switch DHCP snooping is enabled
DHCP snooping is configured on following VLANs: 10
DHCP snooping is operational on following VLANs: 10

**Command to configure ARP inspection for a range of VLANs**
Switch(config)# ip arp inspection vlan 10, 11, 12, 13
Or
Switch(config)# ip arp inspection vlan 10-13

**To view the ARP inspection status**
Switch(config)# show ip arp inspection
