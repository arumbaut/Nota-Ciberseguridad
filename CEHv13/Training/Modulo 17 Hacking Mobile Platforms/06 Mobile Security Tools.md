**Source Code Analysis Tools**

**▪ Syhunt Mobile Source: https://www.syhunt.com**

Syhunt Mobile es una herramienta diseñada para analizar el código fuente de aplicaciones móviles, realizando más de 350 verificaciones de vulnerabilidades en lenguajes como Java y Android, que son los más comunes para el desarrollo de aplicaciones en Android. Además, la herramienta también es compatible con otros lenguajes primarios utilizados para el desarrollo de aplicaciones iOS, como Swift, Objective-C y C.Para iOS, Syhunt Mobile ofrece un conjunto de verificaciones que abarca más de 19 categorías de vulnerabilidades, realizando más de 240 comprobaciones de seguridad.Esta herramienta permite a los editores, desarrolladores y testers de calidad (QA) escanear de forma automática aplicaciones Android e iOS para detectar vulnerabilidades conforme a la lista OWASP Mobile Top 10.

**Reverse Engineering Tools**
▪ Apktool Source: https://apktool.org
Esta herramienta permite decodificar los recursos de la aplicación a una forma cercana a la original, lo que facilita la modificación de los mismos. Una vez realizadas las modificaciones, Apktool puede reconstruir la aplicación para generar un nuevo archivo APK.

**Mobile Pen Testing Toolkits**
▪ ImmuniWeb® MobileSuite Source: https://www.immuniweb.com
ImmuniWeb® MobileSuite aprovecha la tecnología de aprendizaje automático para mejorar y acelerar las pruebas de penetración manual de aplicaciones móviles para iOS y Android. Esta herramienta ofrece pruebas rápidas, escalables y habilitadas para DevSecOps tanto para aplicaciones móviles como para sus backend, proporcionando pautas de remediación personalizadas y un SLA de cero falsos positivos.Además, permite la integración con herramientas de SDLC y CI/CD, así como con WAF (Firewalls de Aplicaciones Web) para detectar vulnerabilidades en el backend móvil.
