
Estos keyloggers son programas instalados de forma remota a través de una red o archivos adjuntos en correos electrónicos en un sistema objetivo para registrar todas las pulsaciones de teclas

 **Application Keylogger****:**Permite observar todo lo que el usuario escribe en correos electrónicos, chats y otras aplicaciones, incluidas contraseñas. También puede rastrear el historial de actividad en Internet. Este tipo de keylogger es invisible y puede monitorear toda una red.

**2. Kernel/Rootkit/Device Driver Keylogger****:**Estos keyloggers operan a nivel del núcleo (kernel), lo que los hace difíciles de detectar para aplicaciones en modo usuario. Funcionan como controladores de teclado falsificados, lo que les permite interceptar todas las pulsaciones de teclas.

**Rootkit Keylogger**: Un controlador de dispositivo de Windows modificado que oculta su presencia y registra todas las teclas presionadas.

**Device Driver Keylogger**: Reemplaza el controlador de entrada/salida (I/O) con una versión alterada que incorpora funciones de keylogging.Los archivos de registro se almacenan en archivos ocultos y se envían al atacante a través de Internet.

**3. Hypervisor-Based Keylogger****:** Este tipo de keylogger opera en un hipervisor de malware que se ejecuta debajo del sistema operativo, permitiendo registrar pulsaciones de teclas sin ser detectado por el propio sistema.

**4. Form-Grabbing-Based Keylogger**: Captura datos ingresados en formularios web antes de que sean cifrados por HTTPS. Intercepta entradas en formularios web al registrar eventos como submit, permitiendo a los atacantes robar credenciales y otra información sensible.

**5. JavaScript-Based Keylogger****:** Los atacantes inyectan etiquetas de JavaScript malicioso en sitios web comprometidos para capturar eventos de teclado, como onKeyUp() y onKeyDown(). Para inyectar estos scripts maliciosos, se emplean técnicas como: **Man-in-the-browser / Manipulator-in-the-browser****,****Cross-site scripting (XSS)**

**6. Memory-Injection-Based Keylogger****:** Modifica las tablas de memoria asociadas con el navegador web y las funciones del sistema para registrar pulsaciones de teclas. Además, los atacantes pueden usar esta técnica para evitar el User Account Control (UAC) en sistemas Windows
