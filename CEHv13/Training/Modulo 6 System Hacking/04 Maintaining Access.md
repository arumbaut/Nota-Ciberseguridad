Después de obtener acceso y escalar privilegios en el sistema objetivo, los atacantes intentan mantener su acceso para continuar explotando el sistema o para usar el sistema comprometido como plataforma para atacar otros equipos dentro de la red. Los atacantes ejecutan remotamente aplicaciones maliciosas como keyloggers, spyware y otros programas dañinos para conservar el acceso al sistema y robar información crítica como nombres de usuario y contraseñas. Además, ocultan sus programas o archivos maliciosos utilizando rootkits, esteganografía, flujos de datos NTFS, entre otros métodos, para asegurar que su acceso al sistema comprometido permanezca sin ser detectado.

#### **Malicious programs attackers execute on target systems can be**

**▪ Backdoors:** Program designed to deny or disrupt the operation, gather information that leads to exploitation or loss of privacy, or gain unauthorized access to system resources.

**▪ Crackers:** Components of software or programs designed for cracking a code or passwords.

**▪ Keyloggers:** These can be hardware or software. In either case, the objective is to record each keystroke made on the computer keyboard.

**▪ Spyware:** Spy software may capture screenshots and send them to a specified location defined by the hacker. For this purpose, attackers have to maintain access to victims’ computers. After deriving all the requisite information from the victim’s computer, the attacker installs several backdoors to maintain easy access to it in the future.

**Keylogger**

Los _keyloggers_ son programas de software o dispositivos de hardware que registran las teclas presionadas en el teclado de una computadora.Como los _keyloggers_ ocultan sus procesos e interfaz, el objetivo no es consciente de que está siendo monitoreado.
