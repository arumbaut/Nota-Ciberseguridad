**Web Application Attacks:**
Incluso si los servidores web están configurados de forma segura o se protegen mediante medidas de seguridad de red como cortafuegos, ==una aplicación web mal codificada desplegada en el servidor web puede proporcionar una vía para que un atacante comprometa la seguridad del servidor web. Si los desarrolladores web no adoptan prácticas de codificación segura al desarrollar aplicaciones web, los atacantes pueden explotar vulnerabilidades y comprometer tanto la seguridad de las aplicaciones web como la del servidor web==

==**Server-Side Request Forgery (SSRF) Attack:**==
Los atacantes explotan vulnerabilidades de falsificación de solicitudes del lado del servidor (SSRF), que surgen del uso inseguro de funciones en una aplicación

**▪ Parameter/Form Tampering:**
El atacante modifica los parámetros intercambiados entre el cliente y el servidor para modificar datos de la aplicación como credenciales de usuario, permisos, así como el precio y la cantidad de productos.

**▪ Cookie Tampering:**
Ocurren cuando una cookie es enviada desde el lado del cliente al servidor.

**▪ Unvalidated Input and File Injection Attacks**:
Entrada no validada e inyección de archivos se realizan suministrando una entrada no validada o inyectando archivos en una aplicación web.

**▪ Session Hijacking**
El secuestro de sesión es un ataque en el que el atacante explota, roba, predice o toma el control del mecanismo de sesión web real y válido para acceder a las partes autenticadas de una aplicación web.

**▪ SQL Injection Attacks**
La inyección SQL explota la vulnerabilidad de seguridad en una base de datos para atacar. El atacante inyecta código malicioso en las cadenas que luego se envían al servidor SQL para su ejecución.

**▪ Directory Traversal**:
El recorrido de directorios es la explotación del protocolo HTTP mediante la cual los atacantes pueden acceder a directorios restringidos y ejecutar comandos fuera del directorio raíz del servidor web manipulando la URL.

**▪ Denial-of-Service (DoS) Attack**:
Un ataque DoS tiene como objetivo finalizar las operaciones de un sitio web o servidor para que no esté disponible para sus usuarios previstos.

**▪ Cross-Site Scripting (XSS) Attacks**:
En este método, un atacante inyecta etiquetas HTML o scripts en un sitio web objetivo.

**▪ Buffer Overflow Attacks**:
El diseño de la mayoría de las aplicaciones web les permite manejar cierta cantidad de datos. Si esa cantidad excede el espacio de almacenamiento disponible, la aplicación puede bloquearse o mostrar algún otro comportamiento vulnerable. Un atacante utiliza esta técnica para aprovecha y satura la aplicación con una cantidad excesiva de datos, provocando un ataque de desbordamiento de búfer.

**▪ Cross-Site Request Forgery (CSRF) Attack**
Un atacante explota la confianza de un usuario autenticado para enviar código malicioso o comandos al servidor web.

**▪ Command Injection Attacks**
En este tipo de ataque, un hacker altera el contenido de la página web utilizando código HTML e identificando los campos de formularios que carecen de restricciones válidas.

**▪ Source Code Disclosure:** 
La divulgación del código fuente puede permitir ocasionalmente a los atacantes acceder a información sensible, como credenciales de base de datos y claves secretas, lo que podría comprometer la seguridad del servidor web.
