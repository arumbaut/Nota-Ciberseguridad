**▪ Listas blancas de aplicaciones (Application Whitelisting)**
La lista blanca de aplicaciones especifica una lista de componentes de aplicaciones como bibliotecas de software, complementos, extensiones y archivos de configuración, o software legítimo que se puede permitir ejecutar en el sistema.  

**▪ Listas negras de aplicaciones (Application Blacklisting)**
La lista negra de aplicaciones especifica las aplicaciones o software maliciosos que no están permitidos para ejecutarse en el sistema o en la red.  
Este método consiste en bloquear las aplicaciones maliciosas que pueden causar daños potenciales o generar ataques.  
El enfoque de la lista negra es centrado en amenazas, por lo que no puede detectar amenazas modernas y puede resultar en ataques que causen pérdida de datos.
