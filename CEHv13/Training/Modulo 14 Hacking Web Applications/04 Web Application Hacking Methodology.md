**Website Mirroring**

El mirroring de sitios web es el proceso de crear una réplica o clon de un sitio web original. Aunque puede utilizarse con fines legítimos como respaldo o acceso sin conexión, los atacantes lo emplean para fines maliciosos, como el phishing o la distribución de malware.
