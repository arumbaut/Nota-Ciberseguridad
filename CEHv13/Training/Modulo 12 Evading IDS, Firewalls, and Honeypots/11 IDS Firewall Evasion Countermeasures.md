**How to Defend Against IDS Evasion**

▪ Apagar los puertos del switch asociados con hosts de ataque conocidos.  
▪ Realizar un análisis en profundidad del tráfico ambiguo de la red para todas las posibles amenazas.  
▪ Utilizar paquetes TCP FIN o Reset (RST) para terminar sesiones TCP maliciosas.

**How to Defend Against Firewall Evasion**

▪ El firewall debe estar configurado de manera que se filtre la dirección IP de un intruso.  
▪ Establecer el conjunto de reglas del firewall para denegar todo el tráfico y habilitar solo los servicios necesarios.  
▪ Si es posible, crear un ID de usuario único para ejecutar los servicios del firewall en lugar de ejecutar los servicios con el ID de administrador o root.
