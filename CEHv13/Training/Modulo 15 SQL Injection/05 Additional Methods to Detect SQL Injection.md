 **Function Testing**

Las pruebas de función son un tipo de técnica de prueba de software en la que un software o un sistema se prueba con un conjunto de entradas de acuerdo con las necesidades del usuario final. La salida obtenida de las entradas se evalúa y se compara con los resultados esperados para verificar si se ajusta a la funcionalidad o los requisitos base de un producto.

For example:

http://certifiedhacker.com/?parameter=123
http://certifiedhacker.com/?parameter=1'
http://certifiedhacker.com/?parameter=1'# 
http://certifiedhacker.com/?parameter=1"
http://certifiedhacker.com/?parameter=1 AND 1=1--http://certifiedhacker.com/?parameter=1'-http://certifiedhacker.com/?parameter=1 AND 1=2--http://certifiedhacker.com/?parameter=1'/*
http://certifiedhacker.com/?parameter=1' AND '1'='1 http://certifiedhacker.com/?parameter=1 order by 1000

#### **▪ Fuzz Testing**

==Utilizada para descubrir errores de codificación mediante la introducción de una gran cantidad de datos aleatorios y observando los cambios en la salida. Las pruebas de fuzzing (fuzzing) son un método de prueba de caja negra. Es una técnica de control de calidad y aseguramiento utilizada para identificar errores de codificación y brechas de seguridad en aplicaciones web==
