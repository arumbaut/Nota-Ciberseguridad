**SD-WAN : Red de Area Amplia Definida por Software  Software Defined WAN**   


![[Pasted image 20260506154051.png]]


![[Pasted image 20260506154338.png]]

Monitorea el rendimiento de las conexiones y regula varios tipos de trafico para garantizar velocidades altas constantes y optimizar la conectividad general
Permite el enrutamiento del trafico basado en aplicaciones
Permite un ajuste preciso como reservar costosos enlaces de alta velocidad para aplicaciones criticas para la empresa
Es compatible con aplicaciones ubicadas en centros de datos locales nubes publicas o privadas o servicios SAS como DropBox AWS entre otros
