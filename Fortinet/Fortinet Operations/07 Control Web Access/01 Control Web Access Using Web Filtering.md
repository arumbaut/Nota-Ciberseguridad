### Para que se utiliza el Web Filtering
- Para controlar y monitorear los sitios webs que los usuarios visitan
- Para mantener la productividad de los usuarios, evitando que entren a sitios no necesarios como redes sociales etc
- Prevenir congestiones de red evitando que se acapare todo el ancho de banda
- Disminuir la exposición a las amenazas basadas en la web
- limitar la responsabilidad legal evitando que entre a sitios con material ofensivo
- Prevenir que vean material inapropiado

El servicio Fortiguard incluye una base de datos de categorías de URL la cual organiza billones de paginas webs en un amplio rango de categorías.

Cada categoría contiene website o web pages que han sido asignadas según su contenido web , cada categoría puede ser permitida o denegada de acuerdo a su contenido

Tiene 3 grupos principales de de consumidores
- Enterprises
- Schools
- Home and Families
