Crear manualmente el HTML necesario para un exploit CSRF puede resultar engorroso, particularmente cuando la solicitud deseada contiene una gran cantidad de parámetros o hay otras peculiaridades en la solicitud. La forma más sencilla de construir un exploit CSRF es utilizar el generador CSRF PoC integrado en Burp Suite Professional:

- Seleccione una solicitud en cualquier lugar de Burp Suite Professional que desee probar o explotar.
- Desde el menú contextual del botón derecho, seleccione Herramientas de participación / Generar CSRF PoC.
- Burp Suite generará algo de HTML que activará la solicitud seleccionada (menos las cookies, que serán agregadas automáticamente por el navegador de la víctima).
- Puede modificar varias opciones en el generador CSRF PoC para ajustar aspectos del ataque. Es posible que tengas que hacer esto en algunas situaciones inusuales para lidiar con características peculiares de las solicitudes.
- Copie el HTML generado en una página web, véalo en un navegador que haya iniciado sesión en el sitio web vulnerable y pruebe si la solicitud prevista se emite correctamente y se produce la acción deseada.
