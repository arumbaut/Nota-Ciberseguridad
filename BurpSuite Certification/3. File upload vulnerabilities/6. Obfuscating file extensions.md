## Obfuscating file extensions

Incluso las listas negras más exhaustivas pueden potencialmente eludirse utilizando técnicas clásicas de ofuscación. Digamos que el código de validación distingue entre mayúsculas y minúsculas y no lo reconoce `exploit.pHp` es de hecho un `.php` archivo. Si el código que posteriormente asigna la extensión del archivo a un tipo MIME es **no** Si distingue entre mayúsculas y minúsculas, esta discrepancia le permite pasar archivos PHP maliciosos más allá de la validación que eventualmente puede ser ejecutada por el servidor.

También puedes lograr resultados similares utilizando las siguientes técnicas:

- Proporcionar múltiples extensiones. Dependiendo del algoritmo utilizado para analizar el nombre del archivo, el siguiente archivo puede interpretarse como un archivo PHP o una imagen JPG: `exploit.php.jpg`
- Agregue caracteres finales. Algunos componentes eliminarán o ignorarán los espacios en blanco finales, los puntos y similares: `exploit.php.`
- Intente utilizar la codificación de URL (o codificación de URL doble) para puntos, barras diagonales y barras diagonales inversas. Si el valor no se decodifica al validar la extensión del archivo, sino que luego se decodifica en el lado del servidor, esto también puede permitirle cargar archivos maliciosos que de otro modo estarían bloqueados: `exploit%2Ephp`
- Agregue punto y coma o caracteres de bytes nulos codificados en URL antes de la extensión del archivo. Si la validación está escrita en un lenguaje de alto nivel como PHP o Java, pero el servidor procesa el archivo utilizando funciones de nivel inferior en C/C++, por ejemplo, esto puede causar discrepancias en lo que se trata como el final del nombre del archivo: `exploit.asp;.jpg` o `exploit.asp%00.jpg`
- Intente utilizar caracteres Unicode multibyte, que pueden convertirse en bytes y puntos nulos después de la conversión o normalización de Unicode. Secuencias como `xC0 x2E`, `xC4 xAE` o `xC0 xAE` puede traducirse a `x2E` si el nombre del archivo se analiza como una cadena UTF-8, pero luego se convierte a caracteres ASCII antes de usarse en una ruta.
