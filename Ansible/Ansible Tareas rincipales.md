Ejercicios Basicos para aprender Ansible

Y automatizaría tareas como:

- Crear usuarios.
- Configurar SSH.
- Instalar Apache y Nginx.
- Desplegar Docker.
- Instalar Wazuh Agent.
- Configurar `sudo`.
- Actualizar todos los servidores.
- Instalar herramientas comunes (`git`, `curl`, `vim`, etc.).
- Configurar `firewalld` o `ufw`.
- Desplegar aplicaciones desde GitHub.
- Configurar cron y copias de seguridad.
