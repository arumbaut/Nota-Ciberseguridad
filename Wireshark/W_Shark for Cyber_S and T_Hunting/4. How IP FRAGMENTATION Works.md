
Probaremos enviar diferente paquetes a la maquina windows para ver el proceso de fragmentacion.

Comando en Windows para ver el tamaño que permite la interface
```
netsh interface ipv4 show interfaces
#Nos fijamos en el MTU

-l -> Especifica la longitud del ping
ping -l 1600 ip  
```

En wireshark en 
Inernet Protocol Version4 -> Flags More Fragments -> More Fragments : Set
Identification -> Nos da el id del paquete y el siguiente paquete deberia tener el mismo identificador.

```
#Aqui le decimos que no configure el bit de fragmentacion aunque se fragmente el paquete
ping -l 1600 -f ip 
```
