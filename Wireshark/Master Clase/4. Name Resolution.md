Para modificar la resolucion de nombre y que en vez de mostrarnos IP nos muestre los nombre de Dominios

Preference->Name Resolution

Resolve Transport Name -> Nos asocia un puerto es decir 80 nos da http lo puertos conocidos.

Resolve Network IP Address -> Nos da la resolucion DNS de la IP . Wireshark resuelve estos nombre a partir del archivo host de nuestro equipo si no se establecen otro parametros dentro de esta pestaña

Podemos ver la listas de resolucion que wireshark esta utilizando

Statistics->Resolve Addresses

Si nos paramos encima de una pack y damos 
Click Derecho->Edit Resolve Name 
Pademos asociar un nombre a una ip
