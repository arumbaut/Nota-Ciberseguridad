En windoes es necesario agregar la ruta al path para poder utilizarlo desde cualquier direccion en la consola

```
C:\Program Files\Wireshark
```


Comandos 
```
dumpcap -h

dumpcap -D #Listar Interfaces

dumpcap -i id_interface

dumpcap -i 1

dumpcap -i -w /usr/adr/data/sample.pcapng #Donde guardar la data recopilada

#Capturar en diferentes paquetes ring buffer, 10 paquetes de 500MB. Cuando llega a 10 empiesa sobreescribiendo el 1 y asi.
dumpcap -i -w /usr/adr/data/sample.pcapng -b filesize:500000 -b files:10


```
