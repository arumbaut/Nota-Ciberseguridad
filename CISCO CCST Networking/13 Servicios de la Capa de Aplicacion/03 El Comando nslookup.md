Cuando configura manualmente un dispositivo para conectividad de red, recuerde que también incluye una dirección de servidor DNS. En el caso de las redes domésticas, DHCP ejecuta esta configuración en el router doméstico. Su ISP proporciona la dirección del servidor DNS al router de su hogar, y luego utiliza el DHCP para enviar la configuración a todos los dispositivos conectados a su red. Cuando escribe el nombre de un sitio web, como [www.cisco.com](http://www.cisco.com/), el cliente DNS que se ejecuta en su dispositivo primero solicita al servidor DNS la dirección IP, como **172.230.155.162**, antes de enviar su solicitud HTTP.

Puede utilizar el comando **nslookup** para descubrir las direcciones IP de cualquier nombre de dominio. En esta actividad del Verificador de sintaxis, practique el ingreso del comando nslookup tanto en Windows como en Linux.
