<p>Las siguientes categorías se utilizan para clasificar los tipos de datos personales:</p><ul><li><b>Datos voluntarios -</b> Estos son creados y compartidos explícitamente por individuos, como perfiles de redes sociales. Este tipo de datos podría incluir archivos de vídeo, imágenes, texto o archivos de audio.</li><li><b>Datos observados -</b> se capturan al registrar las acciones de las personas, como los datos de ubicación cuando usan teléfonos celulares.</li><li><b>Datos inferidos -</b> se trata de datos como una puntuación de crédito, que se basa en el análisis de datos voluntarios u observados.</li></ul><p>El término&nbsp;bit es la abreviatura de “binary&nbsp;digit” (dígito binario) y representa la unidad de datos más pequeña. Cada bit solo puede tener uno de dos valores posibles:&nbsp;0&nbsp;o&nbsp;1.</p><p>Se utilizan tres métodos comunes para transmitir señales en las redes:</p><ul><li><b>Señales eléctricas -</b> La transmisión se logra representando los datos como pulsos eléctricos en un cable de cobre.</li><li><b>Señales ópticas -</b> La transmisión se logra convirtiendo las señales eléctricas en pulsos de luz.</li><li><b>Señales inalámbricas -</b> La transmisión se logra mediante el uso de ondas infrarrojas, microondas o de radio a través del aire.</li></ul>
