Parametros de busqueda de Google para especificar las busquedas

limitar la busqueda a un dominio

```
site:ine.com
```

Buca la palabra admin en la url 
```
inurl:admin
```

Se pueden combinar
```
site:ine.com inurl:admin 
```

Enumerar subdominios 
```
site:*.ine.com
```

```
site:*.ine.com filetype pdf
```
