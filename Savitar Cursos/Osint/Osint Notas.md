The OSINT Cycle

1. **Planning & Direction**: Define objectives, requirements, and scope of the investigation
2. **Collection**: Gather relevant information from various sources
3. **Processing**: Filter, validate, and organize the collected data
4. **Analysis**: Examine the processed information to identify patterns, relationships, and insights
5. **Dissemination**: Present findings in a clear, actionable format
6. **Feedback**: Evaluate the process and results to improve future investigations

Categories of OSINT Tools
- **Search Engines**: Beyond basic Google searches, specialized search engines and advanced operators
- **Social Media Analysis**: Tools for finding, monitoring, and analyzing social media profiles and content
- **Domain and IP Analysis**: Tools for investigating websites, domains, and network infrastructure
- **Geolocation Tools**: Resources for identifying and verifying locations
- **Image and Video Analysis**: Tools for extracting metadata, performing reverse image searches, and analyzing visual content
- **Data Visualization**: Software for presenting complex relationships and findings
- **Archiving Tools**: Resources for accessing historical versions of web content

**Example:** **Common OSINT Tools by Category:**  
  
- **Search Engines**: Google (with advanced operators), DuckDuckGo, Bing, Shodan  
- **Social Media Analysis**: Social Bearing, Twint, Instaloader  
- **Domain Analysis**: WHOIS, VirusTotal, DNSDumpster  
- **Geolocation**: Google Earth, SunCalc, GeoGuessr  
- **Image Analysis**: Google Reverse Image Search, ExifTool, TinEye  
- **Archiving**: Wayback Machine, Archive.today  
- **Data Visualization**: Maltego, Gephi
