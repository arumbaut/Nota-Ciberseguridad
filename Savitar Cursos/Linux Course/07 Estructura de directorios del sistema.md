BIN       Donde se almacenan los binarios ejecutables de usuario
SBIN    Donde se almacenan los binarios ejecutables de usuario root para tareas                                           administrativas (Tareas como arranque, restauración, reparación )
BOOT  Donde se almacenan los archivos necesarios para el arranque del sistema
DEV      Incluye todos los dispositivos de almacenamiento conectados al sistema en forma de                  archivo
ETC      Contiene todos los archivos de configuración tanto a nivel de componentes del OS                       como los programas instalados posteriormente. 
HOHE  Directorio de los usuarios.  También archivos temporales de aplicaciones ejecutadas                   en modo usuario 
LIB         Donde se almacenan todas las bibliotecas esenciales para que se ejecuten los                 LIB64    binarios del sistema. los binarios en /bin  y  /sbin
MEDIA   Punto de montaje para los volumenes que se montan temporalmente
OPT        Extension del dir /usr  contiene los archivos de solo lectura de programas                                         auto contenidos
PROC     Contiene info de los procesos y app que se están ejecutando actualmente en el                              sistema
ROOT     Directorio home del usuario root
SRV         Almacena archivos y directorios relativos a servidores que puedas tener instalados                      en el sistema
SYS          Contiene archivos virtuales que proveen de información respecto al kernel de OS
TMP         Contiene los archivos temporales del OS y aplicaciones 
USR          User System Resource, Almacena todos los archivos de solo lectura relativos a las                         utilidades del usuario incluyendo todo el software instalado mediante los gestores                      de paquetes. 
VAR           Contiene varios archivos con información del system logs , email, info de cache, etc
