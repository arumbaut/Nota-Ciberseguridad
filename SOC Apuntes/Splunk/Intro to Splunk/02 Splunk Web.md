Splunk cuanta con 3 roles predefinidos

Admin: El role mas poderoso con permiso a todo, puede instalar app, ingestar datos, crear objetos de conocimiento para todos los users

Power: Puede crear y compartir objetos de conocimientos para todos los usuario de una app y realizar busquedas en tiempo real

User: Solo puede ver sus propios objetos de conocimiento y aquellos compartidos con el.

Splunk Cloud tiene roles similares

SC_Admin, Power , User

Y roles especificos de cloud
Can_Delete, Token_Auth, App
